# G3 U1 L1.1 — Numero sa Merkado SVG Assets

This revised pack contains only lesson-specific people and required market assets.

## Included

- `background/` — Grade 3 market landscape.
- `people/` — female market vendor and male fish vendor.
- `counting_objects/` — mango, fish, lily pad, three flowers, book, and shell.
- `inventory/` — bananas, egg, cup, candle, pail states, crate, and tray.
- `shells/` — eight individual shell variants.
- `stalls/` — five empty product stalls and one market counter.

## Intentionally excluded

- Koka
- Stars and reward medals
- Sparkles
- Hand cursors
- Confetti
- Generic navigation and interface graphics

## Usage

- Duplicate individual counting objects in code to create exact quantities.
- Keep products separate from stalls so they can be arranged per activity.
- Use `Pail_Empty.svg` while shells are being dragged and `Pail_6_Shells.svg` after completion.
- Render all lesson wording, numbers, and answer labels in the application instead of baking text into these assets.
- All cutouts have transparent backgrounds.
